# Salman Profile

Static profile site for GitHub Pages.

## Files
- `index.html` - main landing page

## Hosting on GitHub Pages
1. Push this repo to GitHub.
2. In the repository settings, open **Pages**.
3. Set the source to the default branch and root folder.
4. Wait for GitHub Pages to build, then open the published URL.

## Sharing the repository
- Add collaborators from **Settings > Collaborators and teams** if you want another GitHub account to have access.
- Or make the repository public so it can be viewed and cloned by anyone.

## Notes
- The page is designed as a single-file static site, so it works without a build step.
- The embedded avatar is retained inside the HTML for portability.
